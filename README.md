## ✨ What is Wishloom?

**Wishloom** turns a birthday into a personalized, chapter-by-chapter story. The sender customizes everything — name, messages, photos, music, a video message — and the recipient gets a magical, animated experience with surprises along the way.

---

## 🎁 Features

- 📖 **7-chapter birthday story** with animated transitions
- 🎨 **7 beautiful themes** — Pastel Garden, Disco After-Dark, Moonlit Constellation, Aurora Dream, Candy Carnival, Ocean Daydream, Golden Birthday
- 🎂 **8 cake styles** — Vanilla, Chocolate, Strawberry, Cupcake, Rainbow, Heart, Two-Tier, Donut
- 🕯️ **5 candle types** — Classic, Candy-Stripe, Sparkler, Heart, Number
- 🖼️ **Photo slideshow** with 8 animated memory cards
- 🎵 **Birthday soundtrack** — upload any audio file
- 🎥 **Personal video message** — upload or record live
- 🎙️ **Voice message** — upload or record up to 30 seconds
- 🎤 **Blow out candles** via microphone (or tap each flame)
- 🎈 **Age balloon pop** — enter their age for a matching balloon show
- ✨ **7 animation styles** — Sparkle, Hearts, Confetti, Fireworks, Bubbles, Petals, Stars
- 🎉 **Party finale overlay** with live confetti
- 🎁 **Gift wrap reveal** screen for the recipient
- 🎵 **Music gate** — a cinematic entry screen before the song plays
- 👁️ **Live preview mode** — see the recipient view instantly
- ♿ **Accessibility-ready** — ARIA labels, keyboard navigation, reduced-motion support

## 🚀 Getting Started

No installation needed. Just open the file in any modern browser.

```bash
# Clone the repo
git clone https://github.com/subratadas7/wishloom.git

# Open in your browser
open wishloom.html
```

Or simply [download the HTML file](./wishloom.html) and open it directly.

---

## 🛠️ How to Use

1. **Open** `wishloom.html` in a browser
2. **Customize** on Scene 1 (the editor):
   - Type the birthday person's name
   - Write your personal messages
   - Pick a theme, cake, and candle style
   - Set the age for the balloon pop
3. **Add media** on the next scenes:
   - Upload photos → they fill the memory slideshow & moment cards
   - Add a birthday song
   - Record or upload a video/voice message
4. **Preview** the recipient experience anytime with the 🎁 button
5. **Share** the HTML file — email it, AirDrop it, or host it on GitHub Pages
